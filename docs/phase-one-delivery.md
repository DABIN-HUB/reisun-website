## 设计体系

采用工程蓝图与现代企业品牌相结合的视觉方向：深海蓝 `#102B50`、品牌蓝 `#245EEA`、冰川青 `#63D7E7`、冷白 `#F4F7FB`、墨蓝 `#172B46`、石板灰 `#5B6B80`。沿用项目自托管 Inter，中文采用系统中文字体栈并独立调整行高与字号。

首页采用原创分层设备—数据—业务插画；服务开放网格、方案深色分栏、案例大图双列、文章编辑式图文布局，避免所有区块使用同一类卡片。所有系统画面、封面、Logo 与 Open Graph 图片均为本地原创资源。

移动端调整为内容重排、折叠菜单、单列案例与纵向流程；320px 提供更紧凑的边距和图形展示。支持可见键盘焦点、跳过导航、Escape 关闭并恢复菜单焦点，以及 reduced-motion。

### 浏览器检查中发现并处理的问题

1. 系统示意小字、CTA 辅助文字与文章元信息对比度偏低：在所属展示组件中调整颜色，未用大面积全局覆盖隐藏问题。
2. 通用容器使用图表 aria-label 但没有图形角色：补充图形语义。
3. 默认代码高亮的橙色 Java 参数对比度不足：使用依赖中实际存在的高对比亮色主题。
4. 表单首次启用时的 CSS 过渡与离屏点击会造成自动化假阴性：等待真实样式稳定、将实际可见控件滚入视口后重查，确认未发生功能缺陷，不为工具时序误改业务代码。
5. 独立像素审阅发现手机首页章节标题拆词：将“不如”“分享”“每一步”所在短语分组，保留原文和字号；重新构建并生成全套截图。
6. 七栏目首屏复审发现方案、文章、联系页面桌面导语有孤字尾行，服务页手机标题拆开“出发”：使用平衡换行与标题插槽分组，实际浏览器逐字行框已确认恢复完整词语。
